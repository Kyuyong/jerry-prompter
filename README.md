# Jerry Prompter

유튜브 촬영을 위한 개인용 프롬프터 PWA 앱입니다.  
스마트폰을 전용 프롬프터 하드웨어에 연결하거나, 독립적으로 사용할 수 있습니다.

**앱 주소**: https://kyuyong.github.io/jerry-prompter/

---

## 주요 기능

| 기능 | 설명 |
|---|---|
| 스크립트 관리 | 여러 개의 스크립트 저장/편집/삭제, 앱 재시작 후에도 유지 |
| 자동 스크롤 | `requestAnimationFrame` 기반 부드러운 자동 스크롤 |
| 속도 조절 | 0.5~10 단계 (0.5 스텝), 촬영 중 실시간 조절 가능 |
| 블루투스 리모콘 | 키보드 입력 리모콘 자동 인식, Space/화살표 키로 제어 |
| 화면 반전 | 좌우/상하 반전 — 하프미러 프롬프터 하드웨어 지원 |
| 색상·폰트 설정 | 배경색/텍스트색 프리셋+컬러피커, 글자 크기/줄간격 슬라이더 |
| 진행률 표시 | 상단 프로그레스 바 + 퍼센트 숫자 |
| Wake Lock | 촬영 중 화면이 꺼지지 않도록 자동 유지 |
| PWA | 홈 화면 설치 가능, 오프라인 동작, 풀스크린 모드 |
| 업데이트 알림 | 새 버전 배포 시 앱 내에서 업데이트 여부 확인 |

## 개발 PC에서 실행하기

### 사전 조건

- [Node.js](https://nodejs.org/) 18 이상
- Git

### 설치 및 실행

```bash
# 1. 저장소 클론
git clone https://github.com/Kyuyong/jerry-prompter.git
cd jerry-prompter

# 2. 패키지 설치
npm install

# 3. 개발 서버 시작
npm run dev
```

브라우저에서 `http://localhost:5173/jerry-prompter/` 로 접속합니다.

> 개발 서버에서는 PWA 서비스 워커가 비활성화됩니다. PWA 기능 테스트는 아래 프리뷰 방법을 사용하세요.

### PWA 빌드 후 로컬 테스트

```bash
# 빌드
npm run build

# 로컬 프리뷰 서버 (서비스 워커 포함)
npm run preview
```

`http://localhost:4173/jerry-prompter/` 로 접속합니다.

### 모바일 기기에서 로컬 테스트

```bash
# 네트워크에 노출되는 개발 서버 시작
npm run dev -- --host
```

터미널에 표시된 `Network:` 주소 (예: `http://192.168.x.x:5173/jerry-prompter/`)를  
같은 Wi-Fi에 연결된 스마트폰 브라우저에서 접속합니다.

## 빌드 및 GitHub Pages 배포

```bash
# 빌드 + GitHub Pages 자동 배포
npm run deploy
```

`gh-pages` 브랜치가 자동 생성되고, 약 1~2분 후  
`https://kyuyong.github.io/jerry-prompter/` 에서 확인할 수 있습니다.

**초기 설정 (최초 1회):**  
GitHub 저장소 → Settings → Pages → Source: **Deploy from a branch** → Branch: `gh-pages`

## 앱 설치 방법 (PWA)

### 안드로이드 (Galaxy, Pixel 등)

1. **Chrome 브라우저**에서 https://kyuyong.github.io/jerry-prompter/ 접속
2. 주소창 우측의 **"앱 설치"** 아이콘 클릭  
   또는 브라우저 메뉴(⋮) → **"앱 설치"** 또는 **"홈 화면에 추가"**
3. 팝업에서 **"설치"** 확인
4. 홈 화면에 생성된 **Jerry Prompter** 아이콘으로 실행

> 설치 후에는 전체화면으로 실행되며, 인터넷 없이도 동작합니다.

### iOS (iPhone)

> **반드시 Safari 브라우저를 사용해야 합니다.** Chrome, Edge 등에서는 PWA 설치가 지원되지 않습니다.

1. **Safari**에서 https://kyuyong.github.io/jerry-prompter/ 접속
2. 하단 툴바의 **공유 버튼** (□↑) 탭
3. 스크롤하여 **"홈 화면에 추가"** 선택
4. 이름 확인 후 우측 상단 **"추가"** 탭
5. 홈 화면에 생성된 **Jerry Prompter** 아이콘으로 실행

## 블루투스 리모콘 사용법

블루투스 프롬프터 리모콘은 대부분 키보드로 인식됩니다.  
리모콘을 기기에 페어링한 후 아래 키 매핑으로 동작합니다.

| 리모콘 버튼 | 키 입력 | 동작 |
|---|---|---|
| 재생/정지 | `Space` 또는 `Enter` | 스크롤 재생 / 일시정지 |
| 속도 + | `↑` (ArrowUp) | 스크롤 속도 올리기 |
| 속도 − | `↓` (ArrowDown) | 스크롤 속도 내리기 |
| 위로 | `←` (ArrowLeft) | 위로 조금 이동 |
| 아래로 | `→` (ArrowRight) | 아래로 조금 이동 |
| 처음 | `Home` | 스크립트 처음으로 |
| 끝 | `End` | 스크립트 끝으로 |

> 실제 리모콘 키값은 제품마다 다를 수 있습니다. 키 참조표는 앱 내 설정 패널 하단에서도 확인할 수 있습니다.
